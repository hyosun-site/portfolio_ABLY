흩어진 상품 정보와 반복 문의라는 문제를 상품마스터로 풀어 유관팀 문의 70% 이상 감소(현업 확인 기준). 건강 서비스는 섭취 경험이 중요하다는 가설로 리뷰 구조를 확장하고 작성 가능 기간을 사전 알림으로 안내해 리뷰 작성률 10% 미만 → 구매건 대비 23.5%.

뉴트리원 공식몰 구축 PM → 서비스 고도화 → D2C 몰 솔루션화 → 상품마스터 → 해외 B2B 전산. 정책·화면 설계, 오픈, 운영 매뉴얼, 개선까지 직접 수행.

03. 변화에 빠른 구조 설계

D2C 몰 공통 기능·API 표준화로 다수 몰에 UI만 변경해 적용. 프로모션 템플릿화로 디자인·개발 없이 즉시 오픈하는 Back Office 설계. 상태별 권한·서류·메일 정책으로 현업 운영 자동화.

04. 지표 정의와 개선

회원·판매 DB 항목 표준화와 GA4·루커 통계 화면으로 운영에서 데이터를 즉시 조회·확인하도록 구축. 언니톡 베타 후 지표 점검·캠페인 조정, 맘대로데이 2019.10 매출 116% 달성.

05. 직군 리딩과 우선순위 결정

협업 방식

문제부터 묻기

제품은 문제를 푸는 수단이라고 생각합니다. 기능을 정하기 전에 어떤 문제가 누구에게 반복되는지, 어떤 지표로 해결을 확인할지를 먼저 정리하고 정책과 화면으로 풀어냅니다.

조율과 투명한 공유

개발·디자인·MD·마케팅·물류·외부 개발사 사이에서 요구사항과 우선순위를 정리하고, 일정이나 범위가 흔들릴 때는 영향과 대안을 사실 그대로 공유합니다.

AI로 만드는 생산성

대시보드, 판매 가이드·매뉴얼, 문구 대조 같은 반복 업무는 AI 도구에 맡기고, 기획자는 방향과 판단에 집중하는 방식으로 문서화·검수 속도를 높입니다.

배울 영역을 인정하고 보완하기

정식 스쿼드 체계와 A/B 테스트 같은 통제된 실험은 경험이 적습니다. 지표 정의와 가설 검증 방식은 데이터 분석가와 함께 일하며 더 단단히 익히겠습니다.
